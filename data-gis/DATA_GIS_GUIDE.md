Data, Sonar Metadata and GIS

Team Member

Maaz — Data, Sonar Metadata and GIS Engineer

Responsibilities

1. Dataset Research

- Find suitable side-scan sonar datasets.
- Verify dataset sources, licences and annotations.
- Document dataset size, classes and limitations.

2. Data Cleaning

- Inspect image quality.
- Identify corrupted or duplicate images.
- Organize annotations and labels.
- Prepare clean data for AI model training.

3. Sonar Metadata

- Identify available sonar metadata.
- Document image dimensions and sensor information when available.
- Check whether genuine geographic coordinates are available.

4. GIS and Mapping

- Organize latitude and longitude data when available.
- Support detection mapping.
- Help visualize detected objects geographically.
- Never invent missing coordinates.

5. Research Coordination

- Maintain the shared research-paper spreadsheet.
- Record paper titles, authors, methods, datasets and limitations.
- Help identify the research gap for AquaRecon.

Expected Deliverables

1. Dataset source and licence documentation.
2. Dataset quality report.
3. Organized dataset metadata.
4. Geographic mapping support.
5. Shared research-paper tracking sheet.

Important Notes

- Verify dataset sources before downloading.
- Do not assume every anomaly is marine debris.
- Do not claim unsupported object dimensions or locations.
- Record unknown and uncertain detections accurately.
